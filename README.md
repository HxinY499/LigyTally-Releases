# Ligy Tally Android Releases

Ligy Tally 安卓安装包公开下载仓库。应用数据仅保存在用户设备本地。

## 下载

- [下载最新版本](https://github.com/HxinY499/LigyTally-Releases/releases/latest)
- [直接下载 Ligy Tally 1.0.0 APK](https://github.com/HxinY499/LigyTally-Releases/releases/download/v1.0.0/LigyTally-1.0.0.apk)

## 安装

1. 在安卓手机上下载 APK。
2. 允许浏览器或文件管理器安装未知应用。
3. 打开 APK 完成安装。

覆盖安装新版本会保留本地数据；卸载应用会删除账单和图片，卸载前请先在应用内导出完整备份。

每个 Release 同时提供 SHA-256 校验文件。
